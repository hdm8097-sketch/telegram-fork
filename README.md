# تليجرام فورك 🛫

عميل تلكرام كامل مفتوح المصدر، مبني بالكامل بجافاسكريبت (Node.js) — «فورك» مستقل يتصل مباشرةً بخوادم تلكرام عبر بروتوكول **MTProto**، بواجهة عربية بأسلوب تلكرام الرسمي.

> مبني باستخدام **Electron** (الواجهة) + **Teleproto** (المكتبة المحدَّثة والمدعومة رسمياً من GramJS لبروتوكول MTProto).

> 🌐 **نسخة ويب:** يعمل مباشرة في المتصفح بدون تثبيت — [https://hdm8097-sketch.github.io/telegram-fork/](https://hdm8097-sketch.github.io/telegram-fork/)

---

## المزايا

- ✅ تسجيل الدخول الرسمي: رقم الهاتف ← رمز التحقق ← كلمة المرور السرية (2FA)
- ✅ استئناف الجلسة تلقائياً عند فتح البرنامج (لا تسجيل دخول مجدداً)
- ✅ قائمة المحادثات مع آخر رسالة، الوقت، والرسائل غير المقروءة
- ✅ فتح المحادثات وعرض سجل الرسائل مع فواصل الأيام
- ✅ إرسال واستقبال الرسائل **لحظياً** (تحديث تلقائي فوري)
- ✅ **إرسال الصور والملفات** (زر الإرفاق، أو لصق صورة مباشرة Ctrl+V)
- ✅ **الإيماءات (Reactions)** — شريط إيماءات في قائمة كل رسالة، والنقر على أي إيماءة مثبتة يضيفها أو يزيلها لحظياً
- ✅ **إعادة التوجيه (Forward)** — زر «إعادة توجيه» ← اختر المحادثة من القائمة
- ✅ **الملصقات (Stickers)** — زر الملصقات بجانب زر الإرفاق، يعرض «ملصقاتك الأخيرة» بمصغّرات فورية، والنقر يرسلها دون رفع (إعادة إرسال من خوادم تلكرام) — والملصقات الواردة تُعرض متحركة في المحادثة
- ✅ **الرد التلقائي (وضع التوفر)** — من زر ⚙ في الشريط الجانبي: فعّل الرد التلقائي مع نص مخصص، يرد مرة واحدة كل 30 دقيقة لكل محادثة (يمنع الإزعاج)
- ✅ **البحث داخل المحادثة** — زر 🔍 في رأس المحادثة، نتائج مع إبراز النص المطابق، والنقر ينقلك للرسالة مباشرة مع وميض
- ✅ **إشعارات سطح المكتب** — تنبيه مع نغمة قصيرة عند وصول رسالة خارج المحادثة المفتوحة، والنقر يفتحها مباشرة
- ✅ **سحب وإفلات الملفات** — أفلت أي ملف داخل نافذة المحادثة ليُرفق فوراً
- ✅ **البحث العالمي** — اكتب حرفين فأكثر في شريط البحث لتصفح نتائج من **كل رسائلك** مع فتح المحادثة بنقرة
- ✅ **الرد الاقتباسي** على أي رسالة مع تنقّل بالنقر للاقتباس
- ✅ **تعديل وحذف** رسائلك (الحذف يشمل الطرف الآخر)
- ✅ **مؤشر «يكتب…»** يُعرض لحظياً (يكتب/يسجل صوتاً/يرسل صورة…) ويُرسل للطرف الآخر
- ✅ تحديث لحظي للتعديلات والحذف الوارد من أجهزتك الأخرى
- ✅ قائمة خيارات لكل رسالة: إيماءات، رد، نسخ النص، إعادة توجيه، تعديل، حذف
- ✅ بحث سريع في المحادثات
- ✅ عرض الصور مع التخزين المؤقت محلياً (تحميل كسول للصور الظاهرة فقط)
- ✅ معاينة بطاقات الروابط، وأيقونات مميزة للملفات والصوتيات والفيديو والملصقات
- ✅ واجهة داكنة بأسلوب تلكرام مع دعم كامل للعربية (RTL)
- ✅ علامة ✓✓ للرسائل المرسلة، ووسم «معدّل» للرسائل المعدّلة
- ✅ فتح الروابط في المتصفح الافتراضي، والصور في نافذة مستقلة

## متطلبات التشغيل

1. **Node.js** (نسخة 18 أو أحدث) — [التحميل](https://nodejs.org)
2. **مفتاح API من تلكرام** (مجاني):
   - ادخل إلى [my.telegram.org](https://my.telegram.org/apps)
   - سجّل الدخول برقم هاتفك
   - من قسم «الأدوات البرمجية / API development tools» أنشئ تطبيقاً جديداً
   - انسخ **App api_id** (رقم) و **Api hash** (نص)

## التشغيل

```powershell
cd telegram-fork
npm install     # مرة واحدة فقط
npm start       # تشغيل البرنامج
```

عند أول تشغيل سيطلب المفتاحين من تلكرام، ثم رقم هاتفك، ثم رمز التحقق الذي يصلك عبر إشعار تطبيق تلكرام (أو SMS).

## النسخة الويب 🌐

نفس البرنامج يعمل كتطبيق ويب كامل في المتصفح (حزمة واحدة عبر esbuild — بلا خادم وسيط):

- **الرابط المباشر:** https://hdm8097-sketch.github.io/telegram-fork/
- يتصل بخوادم تلكرام عبر **WebSocket (wss)** مباشرة من المتصفح — لا وسيط ولا تمرير بياناتك على أي خادم.
- الجلسة تُحفظ في `localStorage` بدل ملف الإعدادات، والوسائط تُعرض مؤقتاً كـ `blob:`.
- بناؤها محلياً: `npm run build:web` ← يُخرج الناتج إلى `docs/` (مصدر GitHub Pages)، وتجربتها محلياً: `node web/serve.js` ثم افتح `http://127.0.0.1:8765/`.

## هيكل المشروع

```
telegram-fork/
├── main.js                 # العملية الرئيسية (Electron): النافذة و IPC
├── preload.js              # الجسر الآمن بين الواجهة والعملية الرئيسية
├── src/
│   ├── tg/
│   │   └── client.js       # خدمة تلكرام: المصادقة، المحادثات، الرسائل، التحديثات
│   └── renderer/
│       ├── index.html      # الواجهة (شاشات الدخول + المحادثات)
│       ├── styles.css      # السمة الداكنة بأسلوب تلكرام
│       └── app.js          # منطق الواجهة
├── web/                    # مصادر النسخة الويب
│   ├── build.js            # حزمة esbuild ← docs/
│   ├── bridge.js           # جسر window.tg للمتصفح (يعادل preload.js)
│   ├── entry.js / setup.js # نقطة الدخول وتهيئة globals (Buffer/process)
│   ├── serve.js            # خادم محلي لتجربة النسخة الويب
│   └── shims/              # بدائل وحدات Node للمتصفح (fs/crypto/zlib/…)
├── docs/                   # ناتج بناء الويب (GitHub Pages)
└── package.json
```

## أين تُحفظ البيانات؟

- **جلسة الدخول والمفتاح:** في مجلد بيانات التطبيق بجهازك (Electron userData) داخل ملف `config.json` — لا تشاركه مع أحد فهو يعادل الدخول لحسابك.
- **الصور المحمّلة:** مجلد `media/` بجانب نفس الملف (تخزين مؤقت).
- **في النسخة الويب:** الجلسة والمفتاح في `localStorage` متصفحك، والوسائط مؤقتة في ذاكرة الصفحة فقط.

## تسجيل الخروج

من زر «⎋» أعلى الشريط الجانبي — يحذف الجلسة من الجهاز ويطلب تسجيل الدخول مجدداً.

## ملاحظات مهمة

- هذا العميل يستخدم **مفتاحك الشخصي** الخاص ويتصل باسمك، وليست به بوت — لذلك التزم بشروط استخدام تلكرام.
- بعض الميزات لم تُنفَّذ بعد: بحث الـ GIFs، الرسائل الصوتية والفيديو، الإيماءات المخصصة (Sticker/Custom Emoji)، والمحادثة السرية. البنية جاهزة للتوسعة.
- رموز الدخول عبر SMS قد تتطلب اشتراك API مدفوعاً للمفاتيح الجديدة (سياسة تلكرام 2025+)، بينما الرمز عبر تطبيق تلكرام يعمل مجاناً.
